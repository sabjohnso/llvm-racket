* Correctness

All FFI signatures match the LLVM C API.

- ~LLVMRunPasses~ parameter order ~(Module, passes, TM, Options)~ ✓
- Returns ~LLVMErrorRef~ (null on success) — correctly handled
- ~check-llvm-error-ref~ is distinct from ~check-llvm-error~ because
  ~LLVMErrorRef~ uses ~LLVMGetErrorMessage~ / ~LLVMDisposeErrorMessage~
  while the legacy bool+char** pattern uses ~LLVMDisposeMessage~.
  This is justified — different C API error mechanisms.
